# Aura · 简约圆角图形化本地博客

> 一款专为深度阅读与本地记录设计的「简约大圆角图形化风格」单页博客系统。纯前端原生实现，无外部第三方依赖，离线即开即用。

---

## 🎨 设计美学与交互特色

- **温润大圆角设计语言**：卡片采用 `24px` 舒适曲率，按钮与标签统一采用药丸形（Pill Shape）胶囊设计，削去视觉尖锐感，降低认知防御。
- **悬浮毛玻璃导航 (Glassmorphic Bar)**：顶部常驻柔和圆角导航栏，集成 Logo、即时搜索框、暗黑/明亮主题切换与快速发布入口。
- **明暗双色主题自适应**：预设日光象牙白与深邃暗夜黑两种高质感配色，支持手动切换并自动记忆用户偏好。
- **流式卡片与沉浸式阅读器**：在“瀑布流博文卡片”与“沉浸式全屏文章阅读页”之间平滑切换，顶部配有实时阅读进度指示条。
- **纯原生 Markdown 渲染**：内置轻量、安全的 Markdown 渲染器，支持标题、多语言代码块、金句引用（Blockquote）、列表、粗体、斜体与预估阅读时间计算。

## 🚀 快速上手与运行

### 方式 1：双击即开（最推荐，零命令零门槛）
在文件资源管理器中，直接双击打开以下文件即可在默认浏览器（Chrome / Edge 等）中运行：
```
outputs/minimal-blog/index.html
```
*已内置自包含脚本包，无需启动任何服务器，无需担心本地跨域限制。*

### 方式 2：使用本地服务运行
在当前项目目录下打开终端，执行：
```bash
npm start
```
然后在浏览器中访问：`http://localhost:3001`

### 运行自动化单元测试
```bash
npm test
```
利用 Node.js 原生测试套件验证 Markdown 解析逻辑、边界用例及数据持久化存储方法（11 项测试 100% 通过）。

## 📂 项目结构说明

```
outputs/minimal-blog/
├── index.html           # 语义化页面结构与弹窗模态框

├── README.md            # 项目使用手册与设计文档
├── src/
│   ├── markdown.js      # 轻量 Markdown 词法解析与阅读时间预估器
│   ├── blogStore.js     # 本地数据中心 (CRUD、LocalStorage、检索、导入导出)
│   ├── app.js           # 页面控制器 (视图切换、主题切换、DOM 事件处理)

    └── blogStore.test.js    # 数据模型、检索过滤与存储单元测试
```

## 💡 核心功能清单

1. **文章浏览与阅读**：预置了 3 篇高质量示例文章（包含圆角设计美学、极简工作流、Codex 敏捷开发手记），支持点赞与阅读时间预估。
2. **全文实时搜索**：顶部搜索框支持对文章标题、正文、标签进行实时过滤，匹配结果毫秒级响应。
3. **标签分类筛选**：横向滚动胶囊标签条，一键切换不同主题分类（如“全部”、“设计美学”、“思考”、“技术”）。
4. **在线撰写与编辑**：点击右上角「写文章」唤起圆角模态框，支持设置封面 Emoji、自定义标签、作者，并在“编辑”与“实时预览”间自由切换。
5. **数据本地私密存储**：所有文章增删改均实时写入浏览器的 `localStorage`，数据完全属于你自己。
6. **数据备份与还原**：页脚提供「📦 导出备份 (JSON)」和「📥 导入数据」按钮，轻松实现跨电脑迁移与永久存档。
